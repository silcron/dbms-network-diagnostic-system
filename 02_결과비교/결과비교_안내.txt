결과 비교 실행

01_DEMO_정상.bat       : DEMO / NORMAL — 기본 접속 성공 모의 결과
02_DEMO_지연경고.bat   : DEMO / WARNING — 응답 지연 모의 결과
03_DEMO_접속실패.bat   : DEMO / DOWN — DB 연결 실패 모의 결과

각 BAT를 실행하면 해당 시나리오의 결과가 브라우저와 실행 창에 표시됩니다.
실제 DB를 중지하거나 비밀번호를 변경하지 않습니다. TCP 통신은 실제로 수행하며 DB 상태만 모의로 생성합니다.
세 DB를 한 화면에서 비교하려면 상위 폴더의 01_프로그램_실행.cmd를 사용하고 진단 시작을 누르세요.
각 DB 카드를 클릭하면 위쪽 상태·색상과 상세 설명이 선택한 DB에 맞게 바뀝니다. 전체 상태는 DB별 상태 영역에 별도로 표시됩니다.

여러 창을 열어 비교할 수 있습니다. 사용 중인 포트는 피하고 다른 프로그램을 종료하지 않습니다.
실행 창의 Enter 또는 Ctrl+C로 각 프로그램을 종료합니다.
